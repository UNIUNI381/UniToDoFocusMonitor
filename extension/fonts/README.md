# Noto Serif

タイマーの数字に使うフォントを同梱しています。実行時の外部通信は不要です。

- 配布元：[Google Fonts / Noto Serif](https://github.com/google/fonts/tree/main/ofl/notoserif)
- 元ファイル：`NotoSerif[wdth,wght].ttf`。内容を変更せず `NotoSerif.ttf` として配置しています。
- ライセンス：SIL Open Font License 1.1。全文は同じフォルダーの `OFL.txt` にあります。
- Copyright 2022 The Noto Project Authors
- タイマー表示にはウェイト700を使います。
