# UniToDo Focus Monitor

UniToDoの作業タイマーが動いている間、X / Twitter・YouTube・自分で登録したサイトの閲覧時間を表示するChrome拡張です。UniToDo本体の改修やビルドは不要です。

## 導入

1. Chromeのアドレス欄へ `chrome://extensions` を入力します。
2. 右上の「デベロッパー モード」をONにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、次のフォルダーを選びます。

   ```text
   E:\CodexProjects\UniToDoFocusMonitor\extension
   ```

4. Chrome右上の拡張機能メニューから **UniToDo Focus Monitor** をピン留めし、開いているX・YouTubeのページを再読み込みします。
5. UniToDoで作業タイマーを開始します。対象サイトを前面で1分見ると、タイマーが表示されます。

表示だけを試す場合は、対象サイトで拡張のアイコンを押し、**表示テスト** を選びます。作業タイマーが停止していても10秒間試せます。実際の計測値は変わりません。プレビューは移動も確認できるよう、表示開始と移動開始の両方を満たす値から表示します。初期設定では `05:00` です。

読み込み元の `extension` フォルダーは移動・削除せず、そのまま残してください。更新時は拡張管理画面の再読み込みボタンを押し、対象サイトも再読み込みします。Chrome 120以降に対応します。

## 計測ルール

| 条件 | 動作 |
| --- | --- |
| UniToDoの作業タイマーが実行中、Chromeが前面、対象タブが選択中 | 1秒につき1秒加算 |
| 対象サイトを開いたまま拡張のポップアップを操作 | 元の対象タブの加算を継続 |
| 60秒に到達 | 最初の1分を含めた値をページに表示 |
| 表示時間が設定した移動開始時間に到達（初期5分） | 移動設定ONならDVD風に動き始める |
| 別のタブ・別のアプリへ移る | 1秒につき1秒減少。最小0秒 |
| 対象サイトの間を移動 | 同じ残高を継続 |
| 一度表示されてから60秒未満に戻る | 0秒になるまで、対象サイトへ戻れば表示を継続 |
| 作業タイマーの停止・別の作業ログへの切り替え | 0秒へリセット |
| 作業名・同じ作業ログの開始日時の編集 | 残高を継続 |
| UniToDoへ接続できない | 残高を保留し、バッジに `!` を表示。自動再接続 |
| モニターOFF | 残高を保留。作業タイマーの停止は引き続き反映 |
| 画面ロック | 加算せず減少 |
| 長いスリープ・処理休止 | 観測できなかった時間をまとめて加算しない |
| Chromeの終了、拡張の再読み込み・更新 | 計測値とタブ除外をリセット。設定は保持 |

例：対象サイトを90秒見て、仕事に30秒戻ると、残高は60秒です。

「仕事中」はタスクの状態名ではなく、実際に動いている作業タイマーで判断します。タスクに紐付かない自由活動タイマーも含みます。

標準の対象は `x.com`・`twitter.com`・`youtube.com` とそのサブドメインです。YouTube Shortsも含みます。対象サイトは拡張の「対象サイト」から追加・削除できます。背面タブの音声再生、対象外サイトの埋め込み動画、Picture-in-Pictureだけの視聴は加算しません。動画を見ている間にマウスやキーボードを操作しなくても加算します。

表示場所は前面の対象サイト内です。表示するのは **`01:23` のような時間だけ**で、見出し・説明文・背景の枠はありません。フォントは同梱した **Noto Serif** で、外部へのフォント取得やOSへのインストールは不要です。数字に薄い縁取りを付け、動画の上でも読めるようにしています。他サイトやWindowsのデスクトップには重ねません。離れている間の残高は、拡張アイコンのポップアップで確認できます。ページ内表示はクリックを通すため、動画の操作を妨げません。

## 表示・設定

- **DVDのように動かす**：初期ON。表示時間が「動き出すまで」の設定値以上になると画面端で反射します。設定時間未満・OFF・OSの動きの低減指定では右下に固定します。減算後の残高が設定時間未満の場合も、赤の固定表示へ戻ります。
- **タイマーのサイズ**：「表示・計測の設定」で16〜160pxに調整できます。初期48px。スライダーを確定すると即時保存します。狭い画面では画面内に収まる寸法まで縮めます。
- **文字色と配置**：右下固定時は赤。移動中は画面端にぶつかるたび、直前と異なる色を8色の候補からランダムに選びます。角で同時に反射した場合は1回だけ変えます。右下固定時はフォント自体の空白も考慮し、右側と下側の見た目の余白を揃えます。サイズを変えても配置を補正します。
- **このタブを15分除外**：仕事用の閲覧に使えます。除外中は残高が減少します。同じタブ内のページ移動にも適用し、期限到達かタブを閉じると解除します。手動解除も可能です。
- **表示を始めるまで**：10〜3,600秒、初期60秒。
- **動き出すまで**：10〜3,600秒、初期300秒。「表示・計測の設定」から変更し、「設定を保存」で反映します。表示開始からの追加待ち時間ではなく、タイマーの値を基準にします。表示開始より短くすると、最初の表示から動きます。既存の設定には300秒を補います。
- **離れている間の減少**：毎秒0.5秒・1秒・2秒。
- **対象サイト**：X / Twitter、YouTubeを個別にON/OFFできます。さらにドメイン単位で最大50件追加・削除できます。
- **表示テスト**：実際の残高を変えず、10秒間プレビューします。

今後の追加候補は、仕事用YouTube動画のURL単位の恒久除外と、その日の閲覧合計です。まずは15分除外と現在の残高で使い、必要な場合に追加すると設定を増やしすぎずに済みます。

## 対象サイトの登録

1. 拡張のアイコンを押して「対象サイト」を開きます。
2. URLまたはドメイン（例：`example.com`）を入力して「追加」を押します。
3. Chromeの確認が出た場合は、そのサイトへのアクセスを許可します。

`https://www.example.com/feed` を入力した場合は `example.com` として登録します。パス・クエリは保存せず、HTTP・HTTPSとサブドメインをまとめて対象にします。ポート指定やIPアドレスは登録できません。標準サイトや登録済みサイトと重なるドメインも重複登録しません。

登録直後に、すでに開いている該当ページにも適用します。通常は再読み込み不要です。削除すると表示・動的スクリプト・追加のアクセス権限を解除します。Chromeの設定から権限だけを解除した場合は、そのサイトの計測を停止し、一覧の「許可する」から再開できます。項目が画面に収まらない場合はポップアップ内をスクロールしてください。

## 連携と保存

```text
UniToDo の既存API（読み取り）
    ↓ GET /api/v1/time-entries/active
Service Worker ── 作業状態・前面タブ・時間の増減を管理
    ├─ 対象サイトの Content Script ── タイマー表示
    └─ 拡張のポップアップ ── 状態・設定・一時除外
```

- 接続先は `http://127.0.0.1:48120/api/v1/time-entries/active` に固定。GETだけを使い、UniToDoのデータやソースを変更しません。
- API取得はホスト権限を持つService Workerで行います。停止時のHTTP 200の空本文とJSON `null` の両方に対応しています。
- 前面の対象サイトから5秒ごとに確認します。背景処理の休止中は30秒アラームとChromeのタブ・ウィンドウイベントで復帰します。作業開始・停止の検出には通常最大約5秒、対象サイトを見ていない場合は通常約30秒かかります。ChromeやOSの都合で遅れる場合があります。
- 拡張ポップアップは、親ウィンドウIDと実際のフォーカス状態を接続経由で送信します。本体の `focused` がfalseになる環境でも計測を継続し、ポップアップの切断・フォーカス喪失・情報の期限切れ時には通常判定へ戻します。通常タブで開いた拡張画面は対象サイトの閲覧として扱いません。
- 通信タイムアウトは2.5秒。閲覧の確認が15秒以上途切れた区間は、過大加算を避けるため加算しません。
- 設定は `chrome.storage.local`、計測値・作業名・タブ除外はブラウザセッション内の `chrome.storage.session` に保存します。作業名や識別子をWebページのコンテンツスクリプトへ渡しません。
- 閲覧履歴・動画タイトル・投稿内容を記録しません。解析サービスや外部サーバーへ送信しません。
- `storage` は状態保存、`alarms` は背景更新、`idle` は画面ロック判定、`scripting` は追加サイトへの表示処理の登録に使います。初期のホスト権限はループバックと標準3サイトです。追加サイトのホスト権限は、サイト登録時にドメインごとに要求します。
- `optional_host_permissions` の `*://*/*` は後から登録するサイト用の宣言で、全サイトへのアクセスを一括で要求するものではありません。追加サイトは実際に許可されたドメインにだけ動的スクリプトを登録します。フォントの `web_accessible_resources` は同梱フォント1ファイルだけを公開します。
- Manifestのホスト権限はポート単位で絞れないため `http://127.0.0.1/*` です。実際の取得URLと拡張の通信ポリシーは48120番へ固定しています。

UniToDoのAPIは外部連携向けの安定契約ではありません。本体更新後に未接続表示になった場合は、APIの応答形式を確認してください。

実装の根拠：[Chromeのクロスオリジン通信](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)、[Service Workerの休止と保存](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle)、[alarms API](https://developer.chrome.com/docs/extensions/reference/api/alarms)、[任意の権限](https://developer.chrome.com/docs/extensions/reference/api/permissions)、[スクリプトの動的登録](https://developer.chrome.com/docs/extensions/reference/api/scripting)。

## 構成・開発確認

| ファイル | 役割 |
| --- | --- |
| `extension/manifest.json` | Chromeへ読み込む拡張の定義 |
| `extension/core.js` | 計測・減算・作業区間の判定 |
| `extension/background.js` | 既存API・Chrome状態・セッション保存 |
| `extension/content.js` | ページ内表示・DVD風の移動・全画面対応 |
| `extension/popup.*` | 拡張の操作画面 |
| `extension/fonts/` | Noto Serifのフォント本体とSIL Open Font License |
| `tests/*.test.mjs` | 計測と背景処理のテスト |
| `scripts/check.mjs` | マニフェストの参照先と構文検査 |
| `scripts/browser-check.mjs` | テスト専用Chromeで拡張を読み込む統合確認 |

拡張の実行にはNode.jsや追加パッケージは不要です。開発確認にはNode.js 22以降を使います。

```powershell
node --test tests/*.test.mjs
node scripts/check.mjs
```

ブラウザ統合確認はPlaywrightがある環境で実行できます。`FOCUS_PLAYWRIGHT_PATH` でPlaywrightのインストール先、`FOCUS_CHROME_PATH` でChrome実行ファイルを指定できます。Chromeの拡張デバッグAPIを使うため、新しいChromeを使用してください。

```powershell
node scripts/browser-check.mjs
```

統合確認はUniToDoが起動している状態で実行します。最初に既存APIへのGET接続を確認した後、テスト用Chrome内だけで作業ログの応答を差し替えます。YouTubeオリジンのテストページで表示を確認し、実サービスのログインや動画再生は行いません。追加サイトの確認では、隔離プロファイルのChrome管理画面APIで `example.com` だけを事前許可し、実際の拡張フォームから登録・削除します。テスト用プロファイル、結果、画像は `.test-artifacts` に保存します。

Chromeで、既存APIへの接続、1分表示、初期設定の5分・変更した2分での移動開始、開始時間の保存と再読込、反射時の色変更、固定表示への復帰と赤色、Noto Serifの読み込み、サイズ変更、ポップアップへのフォーカス移動時の加算継続、追加サイトの登録・既存ページと次回読み込みへの適用・削除、全画面表示、除外、対象外タブでの減算、通信切断表示を確認しました。計測・背景処理の自動テストは34件です。

## 表示されない場合

1. 拡張を開き、「UniToDo 未接続」ならUniToDoを起動します。
2. 「作業タイマー待ち」ならUniToDoで作業タイマーを開始します。
3. 対象サイトのページを再読み込みし、Chromeを前面にします。
4. 対象サイトのON/OFF、モニターON、15分除外の状態を確認します。
5. 「表示テスト」でページ内表示だけを確認します。
